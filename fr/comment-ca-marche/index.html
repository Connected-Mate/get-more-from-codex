Comment ça marche

Ce qui se passe entre votre abonnement et votre agent

Tout tourne sur votre ordinateur. Voici où vit votre connexion, ce que chaque outil envoie à OpenAI, et comment brancher votre agent.

Le circuit

Connectez-vous une fois, chaque appel la réutilise

  1. 01

    Connexion officielle

    auth.openai.com en OAuth + PKCE. La réponse revient sur localhost:1455, sur votre ordinateur.

  2. 02

    Jeton local

    Rangé dans votre dossier personnel, lisible par vous seul. Renouvelé tout seul.

  3. 03

    Serveur MCP

    Un petit programme Node.js que votre agent lance. Il propose des outils comme generate_image ou generate_speech.

  4. 04

    Votre fichier

    L’image ou l’audio est écrit dans votre projet. Rien ne passe par nos serveurs : il n’y en a pas.

Sécurité

Votre mot de passe ne touche jamais les outils

  • Vous vous connectez sur la page d’OpenAI, dans votre propre navigateur.
  • Le jeton ne quitte jamais votre ordinateur, sauf pour parler à OpenAI.
  • npm run logout dans le dossier d’un outil supprime sa connexion enregistrée. Celle du Codex CLI n’est pas touchée.
  • Open source : chaque ligne se lit sur GitHub.

Brancher votre agent

Choisissez votre agent. La même installation marche pour les deux outils.

Laissez votre agent l’installer · GPTImage

Copiez ce texte et collez-le dans votre agent de code (Claude Code, Codex, Cursor ou un autre). Il installe l’outil, le branche, vous demande de vous connecter à ChatGPT dans votre navigateur, et génère une image de test.

Texte d’installation
Installe GPTImage pour moi : https://github.com/Connected-Mate/gptimage (un serveur MCP open source qui génère des images avec ma connexion ChatGPT). Dis-moi ce que tu fais à chaque étape.

1. Lance `node -v`. Il faut la version 20 ou plus. Sinon, arrête-toi et dis-moi d’installer Node.js depuis nodejs.org.
2. Si ~/gptimage n’existe pas, lance `git clone https://github.com/Connected-Mate/gptimage.git ~/gptimage`. S’il existe, lance `git -C ~/gptimage pull`. Puis `cd ~/gptimage && npm install`.
3. Enregistre le serveur MCP dans l’agent que tu es. La commande est `node <chemin complet de ~/gptimage>/src/server.js`.
   - Claude Code : lance `./install.sh --no-login` dans ~/gptimage (il enregistre le serveur pour tous les projets et ajoute la compétence /gptimage).
   - Codex : `codex mcp add gptimage -- node <chemin complet>/src/server.js`
   - Cursor : dans ~/.cursor/mcp.json, ajoute une entrée "gptimage" sous "mcpServers" avec "command": "node" et "args": ["<chemin complet>/src/server.js"]. Garde les autres entrées.
   - Tout autre agent : ajoute cette commande à tes réglages MCP.
4. Lance `npm run status` dans ~/gptimage. Si je ne suis pas connecté, lance `npm run login` : il ouvre la page de connexion officielle de ChatGPT dans mon navigateur. Dis-moi d’y finir la connexion, puis attends. Ne me demande jamais de mot de passe ni de jeton. Si le navigateur ne peut pas s’ouvrir d’ici, demande-moi de lancer moi-même `npm run login` dans ~/gptimage.
5. Teste : `npm run gen -- -p "a small watercolor fox, test image" -o ~/gptimage-test.png --size 1024x1024`, puis montre-moi le chemin de l’image.
6. Dis-moi de te redémarrer pour que le nouvel outil gptimage soit chargé.

À savoir : ceci réutilise ma connexion ChatGPT de Codex. Ce n’est pas une API officielle d’OpenAI : usage personnel uniquement.

Vous gardez la main : l’agent montre chaque étape, et vous ne tapez votre mot de passe que sur la page de connexion d’OpenAI.

Questions

C’est vraiment gratuit ?

Les outils sont gratuits et open source. GPTImage est décompté de l’abonnement ChatGPT que vous payez déjà, dans ses limites : pas de facture à l’image, pas d’abonnement en plus. GPTVoice est différent : il peut être facturé sur votre compte API OpenAI (voir plus bas).

GPTVoice coûte-t-il quelque chose ?

Peut-être. Les appels de voix passent par l’organisation API OpenAI personnelle liée à votre compte : ils peuvent donc être prélevés sur ses crédits API ou sa carte, environ 0,03 à 0,08 $ par minute d’audio. Rien ne prouve qu’ils soient inclus dans votre abonnement ChatGPT. Après vos premières voix, vérifiez platform.openai.com/usage. Si des frais non voulus apparaissent, arrêtez d’utiliser GPTVoice.

Faut-il une clé API ?

Non. Vous vous connectez une fois avec votre compte ChatGPT, dans votre propre navigateur.

Quel abonnement ChatGPT faut-il ?

Un abonnement payant actif, comme Plus ou Pro. Ce que vous pouvez produire dépend des limites de votre formule.

Ça marche avec Codex, Cursor ou d’autres agents ?

Les deux outils sont des serveurs MCP standard : tout agent compatible MCP peut les lancer. Ils sont testés avec Claude Code. Codex et Cursor utilisent la même installation standard montrée plus haut, mais nous ne les avons pas encore testés.

J’ai une erreur « 429 ». Que faire ?

Vous avez atteint la limite de votre abonnement pour le moment. Patientez un peu, réessayez, et évitez les grosses séries d’un coup.

Puis-je l’utiliser pour mon entreprise ?

Nous le déconseillons. C’est prévu pour un usage personnel, sur votre ordinateur. Pour un usage commercial ou à gros volume, utilisez l’API officielle d’OpenAI.

À lire

C’est une zone grise, et nous le disons

  • Non officiel. « Se connecter avec ChatGPT » est prévu pour Codex. Ces outils réutilisent cette connexion pour atteindre les modèles d’image et de voix d’OpenAI. Ça marche et c’est très répandu, mais ce n’est pas une API officiellement prise en charge.
  • Usage personnel. Gardez-le personnel et sur votre machine.
  • La voix peut être payante. Les appels de GPTVoice passent par votre organisation API OpenAI personnelle et peuvent y être facturés. Vérifiez platform.openai.com/usage.
  • Limites. Un usage intensif peut déclencher les limites de votre abonnement (erreur 429). Patientez et réessayez.
  • Risque pour le compte. Au pire, OpenAI pourrait restreindre votre compte. En utilisant ces outils, vous acceptez ce risque.
  • Voix de synthèse. Ne les utilisez jamais pour imiter une personne réelle.
  • Aucun lien officiel. Ni avec OpenAI, ni avec Anthropic, ni avec Cursor. Respectez les conditions d’utilisation d’OpenAI.
