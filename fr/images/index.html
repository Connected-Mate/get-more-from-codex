GPTImage

Des images pour votre projet, créées par votre agent

Demandez à votre agent de code un logo, une image d’accueil ou un storyboard. GPTImage la crée avec GPT Image 2 via votre abonnement ChatGPT et l’enregistre à côté de votre code.

Pour ceux qui construisent

Fini de quitter votre éditeur pour chercher une image

  • Sites et applis

    Images d’accueil, illustrations d’écrans vides, icônes et fonds, générés à la bonne taille.

  • Marque et produit

    Pistes de logo, maquettes, bannières et posts réseaux sociaux à partir de vos propres éléments de marque.

  • Histoires et vidéo

    Des storyboards et des images au style cohérent, prêts pour une voix off.

Sous le capot

Comment GPTImage récupère vos images

Pas de magie et pas de clé API. Voici exactement ce qui se passe, étape par étape.

  1. 01

    Vous vous connectez une fois

    Une fenêtre de navigateur s’ouvre sur la page de connexion officielle de ChatGPT (OAuth avec PKCE sur auth.openai.com). Vous y tapez votre mot de passe, jamais dans l’outil.

  2. 02

    Le jeton reste sur votre ordinateur

    Il est enregistré dans ~/.gptimage/auth.json, ou repris de ~/.codex/auth.json si le Codex CLI est connecté. Il est renouvelé tout seul quand il expire.

  3. 03

    Votre agent appelle l’outil

    L’outil MCP generate_image envoie votre demande et vos images de référence à chatgpt.com/backend-api/codex/responses, le même service que Codex, en demandant l’outil d’image (GPT Image 2).

  4. 04

    L’image arrive dans votre projet

    Le résultat reçu est décodé en PNG et enregistré où vous l’avez demandé. Un fichier existant n’est jamais écrasé : les nouvelles versions prennent -v2, -v3.

Coût : les créations sont décomptées des limites de votre abonnement ChatGPT. Pas de facture à l’image. Un usage intensif peut atteindre la limite de votre abonnement (erreur 429).

Comment ça marche, en détail

GPTImage

Disponible

Des images et des retouches par GPT Image 2, directement depuis votre agent de code.

  • Part de vos images de référence : styles, éléments de marque, croquis. Il les range dans un dossier references/ pour que chaque nouvelle image soit meilleure.
  • Toutes les tailles jusqu’à 3840 px sur le grand côté : carré, paysage ou portrait.
  • N’écrase jamais un fichier. Chaque nouvelle version est enregistrée à côté de la précédente.
  • Trois outils pour votre agent : generate_image, list_references, image_auth_status. Et une commande de terminal en une ligne.

Exemple de demande

Génère un renard roux à l’aquarelle dans la neige et enregistre-le dans renard.png avec l’outil gptimage.

Installer et brancher votre agent

Clonez l’outil une fois, puis branchez l’agent que vous utilisez. Demande Node.js 20 ou plus récent et un abonnement ChatGPT payant (Plus, Pro…). Le script d’installation est prévu pour macOS et Linux.

Claude CodeTesté

./install.sh ajoute l’outil pour tous vos projets, avec sa compétence. Redémarrez Claude Code ensuite.

Commandes
git clone https://github.com/Connected-Mate/gptimage.git
cd gptimage
npm install
./install.sh

Codex CLIInstallation MCP standard, pas encore testée

Une commande ajoute l’outil à Codex (le CLI, l’extension IDE et l’appli partagent ~/.codex/config.toml).

Commandes
cd /path/to/gptimage
npm install
npm run login
codex mcp add gptimage -- node /path/to/gptimage/src/server.js

Ensuite, connectez-vous une fois : npm run login dans le dossier de l’outil ouvre la page de connexion officielle de ChatGPT. Déjà connecté au Codex CLI ? La connexion est réutilisée. Remplacez /path/to/ par le dossier où vous avez cloné l’outil.

CursorInstallation MCP standard, pas encore testée

Ajoutez le serveur dans ~/.cursor/mcp.json (tous les projets) ou .cursor/mcp.json (un projet).

mcp.json
{
  "mcpServers": {
    "gptimage": {
      "command": "node",
      "args": ["/path/to/gptimage/src/server.js"]
    }
  }
}

Ensuite, connectez-vous une fois : npm run login dans le dossier de l’outil ouvre la page de connexion officielle de ChatGPT. Déjà connecté au Codex CLI ? La connexion est réutilisée. Remplacez /path/to/ par le dossier où vous avez cloné l’outil.

Autre client MCPInstallation MCP standard, pas encore testée

C’est un serveur MCP standard (stdio) : indiquez cette commande à votre client.

Commandes
command: node
args:    /path/to/gptimage/src/server.js

Ensuite, connectez-vous une fois : npm run login dans le dossier de l’outil ouvre la page de connexion officielle de ChatGPT. Déjà connecté au Codex CLI ? La connexion est réutilisée. Remplacez /path/to/ par le dossier où vous avez cloné l’outil.
