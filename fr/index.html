Votre abonnement ChatGPT, dans votre agent de code

Vous payez déjà ChatGPT pour utiliser Codex. Deux petits outils open source permettent à Claude Code, Codex, Cursor ou n’importe quel agent MCP d’utiliser cette même connexion pour créer des images et des voix. Pas de clé API à créer, rien de plus à payer en abonnement.

Créer des imagesCréer des voix
  • Pas de clé API
  • Pas d’abonnement en plus
  • Marche avec votre agent de code
  • Open source (MIT)
En toute franchise.

Ces outils réutilisent la connexion « Se connecter avec ChatGPT » de Codex. Ce n’est pas une API officielle d’OpenAI : restez sur un usage personnel. Les images sont décomptées de votre abonnement ChatGPT ; les voix peuvent être facturées sur votre compte API OpenAI. Lire les détails.

L’idée

Branchez votre abonnement sur votre agent

  1. 01

    Votre abonnement

    Celui que vous utilisez déjà pour Codex. Sa connexion sait faire plus que du code.

  2. 02

    Une prise MCP

    GPTImage ou GPTVoice se connecte une fois, garde le jeton sur votre ordinateur et le transforme en outils que votre agent peut appeler.

  3. 03

    Votre agent crée

    Demandez avec vos mots : « fais une image d’accueil », « enregistre la voix off ». Le fichier arrive dans votre projet.

Deux outils

Un pour les images, un pour les voix

GPTImage

Disponible

Logos, illustrations, maquettes, bannières, storyboards. Votre agent les crée avec GPT Image 2 et les range dans votre projet.

  • Décompté de votre abonnement ChatGPT
  • Part de vos images de référence
  • N’écrase jamais un fichier
Découvrir GPTImage →

GPTVoice

Avant-première

Des voix off pour le motion design, les vidéos explicatives, les pubs et les podcasts. 10 voix, émotions, chuchotements et rires, sous-titres compris.

  • 10 voix, en anglais et en français
  • Lu mot pour mot
  • MP3 ou WAV, plus les sous-titres
Découvrir GPTVoice →

Compatible avec

L’agent que vous utilisez déjà

Les deux outils sont des serveurs MCP standard. Votre agent les voit comme de nouvelles compétences.

  • Claude Code
  • Codex CLI
  • Cursor
  • Autre client MCP

Testé avec Claude Code. Codex, Cursor et les autres clients MCP utilisent la même installation standard, pas encore testée.
