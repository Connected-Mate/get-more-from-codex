How it works

What happens between your subscription and your agent

Everything runs on your computer. Here is where your sign-in lives, what each tool sends to OpenAI, and how to connect your agent.

The flow

Sign in once, then every call reuses it

  1. 01

    Official login

    auth.openai.com with OAuth + PKCE. The callback comes back to localhost:1455 on your computer.

  2. 02

    Local token

    Stored in your home folder, readable only by you. Refreshed automatically.

  3. 03

    MCP server

    A small Node.js program your agent starts. It exposes tools like generate_image or generate_speech.

  4. 04

    Your file

    The image or audio is written in your project. Nothing goes through our servers: there are none.

Safety

Your password never touches the tools

  • You log in on OpenAI’s own page, in your own browser.
  • The token never leaves your computer except to talk to OpenAI.
  • npm run logout in a tool’s folder deletes its stored sign-in. Your Codex CLI sign-in is left untouched.
  • Open source: every line can be read on GitHub.

Connect your agent

Pick your agent. The same setup works for both tools.

Let your agent install it · GPTImage

Copy this prompt and paste it into your coding agent (Claude Code, Codex, Cursor or another). It installs the tool, connects it, asks you to sign in to ChatGPT in your browser, and makes a test image.

Install prompt
Install GPTImage for me: https://github.com/Connected-Mate/gptimage (an open-source MCP server that generates images with my ChatGPT sign-in). Tell me what you do at each step.

1. Run `node -v`. It must be 20 or newer. If not, stop and tell me to install Node.js from nodejs.org.
2. If ~/gptimage does not exist, run `git clone https://github.com/Connected-Mate/gptimage.git ~/gptimage`. If it exists, run `git -C ~/gptimage pull`. Then `cd ~/gptimage && npm install`.
3. Register the MCP server in the agent you are. The command is `node <full path of ~/gptimage>/src/server.js`.
   - Claude Code: run `./install.sh --no-login` in ~/gptimage (it registers the server for all projects and adds the /gptimage skill).
   - Codex: `codex mcp add gptimage -- node <full path>/src/server.js`
   - Cursor: in ~/.cursor/mcp.json, add a "gptimage" entry under "mcpServers" with "command": "node" and "args": ["<full path>/src/server.js"]. Keep the other entries.
   - Any other agent: add that command to your MCP settings.
4. Run `npm run status` in ~/gptimage. If I am not signed in, run `npm run login`: it opens the official ChatGPT sign-in page in my browser. Tell me to finish signing in there, then wait. Never ask me for a password or a token. If the browser cannot open from here, ask me to run `npm run login` myself in ~/gptimage.
5. Test it: `npm run gen -- -p "a small watercolor fox, test image" -o ~/gptimage-test.png --size 1024x1024`, then show me the path of the image.
6. Tell me to restart you so the new gptimage tool is loaded.

Note: this reuses my ChatGPT sign-in for Codex. It is not an official OpenAI API, so keep the use personal.

You stay in control: the agent shows each step, and you type your password only on OpenAI’s own sign-in page.

Questions

Is it really free?

The tools are free and open source. GPTImage counts against the ChatGPT plan you already pay for, within its limits: no per-image bill, no extra subscription. GPTVoice is different: it may be charged to your OpenAI API account (see below).

Does GPTVoice cost anything?

Possibly. Voice calls are routed to the personal OpenAI API organization linked to your account, so they may be charged to its API credits or card, roughly $0.03–0.08 per minute of audio. It is not proven that they are included in your ChatGPT plan. After your first voices, check platform.openai.com/usage. If you see charges you don’t want, stop using GPTVoice.

Do I need an API key?

No. You sign in once with your ChatGPT account, in your own browser.

Which ChatGPT plan do I need?

An active paid plan, such as Plus or Pro. How much you can make depends on your plan’s limits.

Does it work with Codex, Cursor or other agents?

Both tools are standard MCP servers, so any agent that supports MCP can start them. They are tested with Claude Code. Codex and Cursor use the same standard setup shown above, but we have not tested them yet.

I get a “429” error. What now?

You reached your plan’s limit for now. Wait a bit and try again, and avoid large batches in one go.

Can I use it for my business?

We advise against it. This is meant for personal use on your own computer. For commercial or high-volume work, use the official OpenAI API.

Please read

This is a grey area, and we say so

  • Unofficial. “Sign in with ChatGPT” is meant for Codex. These tools reuse that login to reach OpenAI’s image and voice models. It works and is widely done, but it is not an officially supported API.
  • Personal use. Keep it personal and local.
  • Voice may cost money. GPTVoice calls go to your personal OpenAI API organization and may be charged there. Check platform.openai.com/usage.
  • Rate limits. Heavy use can trigger your plan’s limits (error 429). Wait and retry.
  • Account risk. In the worst case, OpenAI could restrict your account. By using these tools, you accept that risk.
  • Synthetic voices. Never use them to impersonate a real person.
  • Not affiliated. No link with OpenAI, Anthropic or Cursor. Follow OpenAI’s terms of use.
