For Claude Code users with a ChatGPT plan

Get more from Codex from your OpenAI subscription

The “Sign in with ChatGPT” you use for Codex can do more than code. Two free, open-source tools let Claude Code use it to make images and voices. Turn both into visuals, narration, ads and short films.

How it works

Sign in once. Then just ask.

  1. 01

    Install

    Copy four lines into your terminal. The tool is added to Claude Code for every project on your computer.

  2. 02

    Sign in with ChatGPT

    Your browser opens on the official ChatGPT login. You type your password there, never in the tool.

  3. 03

    Ask Claude

    In plain words, in any project. Claude picks the tool, makes the file and saves it next to your work.

Two tools

One for pictures, one for voices

Each is a small MCP server: a plug-in that gives Claude Code a new skill. Both use the same ChatGPT sign-in.

GPTImage

Available

Images and edits from GPT Image 2, straight from Claude Code.

Logos, illustrations, mockups, banners, textures, storyboards. The pictures and the storyboard on this page were made with it.

  • Works from your reference images: style samples, brand assets, sketches. It keeps them in a references/ folder so each new image gets better.
  • Never overwrites a file. Each new version is saved next to the last one.
  • Three tools for Claude: generate_image, list_references, image_auth_status.
  • Also works as a one-line command in the terminal.

Example request

Generate a watercolor red fox in snow and save it to fox.png using the gptimage tool.

Install
git clone https://github.com/Connected-Mate/gptimage.git
cd gptimage
npm install
./install.sh

Needs Node.js 20 or newer, Claude Code and a paid ChatGPT plan (Plus, Pro…). The script is for macOS and Linux. Restart Claude Code afterwards.

GPTVoice

Preview

Text in, voice out. A voice studio for Claude Code, on your ChatGPT plan.

Ask Claude for a narration, a voice-over or a dialogue, and get an MP3 or WAV back. It drives OpenAI's realtime voice model with your ChatGPT sign-in, and checks that every word was read.

What it does

  • 10 voices (marin, cedar, coral, sage…). Every voice speaks every language: the text decides.
  • Direct the delivery in plain words: emotion, pace, accent, whispering.
  • Long texts are split at sentences and joined into one file with natural pauses.
  • Word-for-word reading: each passage is compared with your text and re-recorded if it drifts.
  • Dialogues with several voices in a single audio file.
  • Optional subtitles (.srt) for your video editor, and transcription of any audio file.

Images + voice

A short film, from one idea

Here is the workflow for a 30-second film called The Keeper. The three frames below are real: each was made with GPTImage from a single request.

  1. Write

    Ask Claude for a short script cut into scenes, one line of narration per scene.

  2. Paint

    GPTImage draws one frame per scene. Reuse the first frame as a reference to keep the same look.

  3. Voice

    GPTVoice reads the narration, with subtitles to time your shots.

  4. Assemble

    Ask Claude to join frames and audio into a video with ffmpeg (free, installed separately).

The same recipe works for

  • a product ad with a voice-over
  • an explainer video for your app
  • a podcast intro
  • social posts with captions read aloud
  • a bedtime story with pictures

Questions

Is it really free?

The tools are free and open source. What they do counts against the ChatGPT plan you already pay for, within its limits. There is no per-image bill and no extra subscription.

Do I need an API key?

No. You sign in once with your ChatGPT account, in your own browser. The tool never sees your password.

Which ChatGPT plan do I need?

An active paid plan, such as Plus or Pro. How much you can make depends on your plan’s limits.

Does it work outside Claude Code?

It is built and tested for Claude Code. GPTImage is a standard MCP server, so other MCP apps may work, but they are not tested. It also has a terminal command.

Where is my sign-in stored?

On your computer only, in ~/.gptimage/auth.json (or your existing Codex CLI sign-in). It is sent only to OpenAI. Run npm run logout to remove it.

I get a “429” error. What now?

You reached your plan’s limit for now. Wait a bit and try again, and avoid making large batches in one go.

Can I use it for my business?

We advise against it. This is meant for personal use on your own computer. For commercial or high-volume work, use the official OpenAI API.

Where does voice usage count?

GPTVoice uses OpenAI’s realtime voice model, which accepts your ChatGPT sign-in (OpenAI’s paid speech API refuses it). OpenAI does not document where that usage is counted. After your first voices, check platform.openai.com/usage: if anything shows up there, stop.

Please read

This is a grey area, and we say so

  • Unofficial. “Sign in with ChatGPT” is meant for Codex. These tools reuse that login to reach OpenAI’s image and voice models. It works and is widely done, but it is not an officially supported API.
  • Personal use. Keep it personal and local.
  • Rate limits. Heavy use can trigger your plan’s limits (error 429). Wait and retry.
  • Account risk. In the worst case, OpenAI could restrict your account. By using these tools, you accept that risk.
  • Not affiliated. No link with OpenAI or Anthropic. Follow OpenAI’s terms of use.
