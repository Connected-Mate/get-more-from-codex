GPTImage

Images for your project, generated by your agent

Ask your coding agent for a logo, a hero image or a storyboard. GPTImage generates it with GPT Image 2 through your ChatGPT plan and saves it next to your code.

Under the hood

How GPTImage gets your images

No magic and no API key. This is exactly what happens, step by step.

  1. 01

    You sign in once

    A browser window opens on the official ChatGPT login (OAuth with PKCE at auth.openai.com). You type your password there, never in the tool.

  2. 02

    The token stays on your computer

    It is saved in ~/.gptimage/auth.json, or reused from ~/.codex/auth.json if the Codex CLI is signed in. It is refreshed automatically when it expires.

  3. 03

    Your agent calls the tool

    The MCP tool generate_image sends your prompt and reference images to chatgpt.com/backend-api/codex/responses, the same backend Codex uses, asking for the image tool (GPT Image 2).

  4. 04

    The image lands in your project

    The streamed result is decoded into a PNG and saved where you asked. Existing files are never overwritten: new versions get -v2, -v3.

Cost: generations count against your ChatGPT plan’s limits. There is no per-image bill. Heavy use can hit your plan’s rate limit (error 429).

How it works, in detail

GPTImage

Available

Images and edits from GPT Image 2, straight from your coding agent.

  • Works from your reference images: style samples, brand assets, sketches. It keeps them in a references/ folder so each new image gets better.
  • Any size up to 3840 px on the long edge: square, landscape or portrait.
  • Never overwrites a file. Each new version is saved next to the last one.
  • Three tools for your agent: generate_image, list_references, image_auth_status. Plus a one-line terminal command.

Example request

Generate a watercolor red fox in snow and save it to fox.png using the gptimage tool.

Install and connect your agent

Clone the tool once, then connect the agent you use. Needs Node.js 20 or newer and a paid ChatGPT plan (Plus, Pro…). The install script is for macOS and Linux.

Claude CodeTested

./install.sh registers the tool for every project and adds the skill. Restart Claude Code afterwards.

Commands
git clone https://github.com/Connected-Mate/gptimage.git
cd gptimage
npm install
./install.sh

Codex CLIStandard MCP setup, not tested yet

One command adds the tool to Codex (CLI, IDE extension and desktop app share ~/.codex/config.toml).

Commands
cd /path/to/gptimage
npm install
npm run login
codex mcp add gptimage -- node /path/to/gptimage/src/server.js

Then sign in once: npm run login in the tool’s folder opens the official ChatGPT login in your browser. Already signed in to the Codex CLI? It is reused. Replace /path/to/ with the folder where you cloned the tool.

CursorStandard MCP setup, not tested yet

Add the server to ~/.cursor/mcp.json (all projects) or .cursor/mcp.json (one project).

mcp.json
{
  "mcpServers": {
    "gptimage": {
      "command": "node",
      "args": ["/path/to/gptimage/src/server.js"]
    }
  }
}

Then sign in once: npm run login in the tool’s folder opens the official ChatGPT login in your browser. Already signed in to the Codex CLI? It is reused. Replace /path/to/ with the folder where you cloned the tool.
